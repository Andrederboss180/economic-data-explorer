Sprechernotiz
Um die Entwicklung mit Codex nachvollziehbar zu machen, habe ich Git und GitHub verwendet.

Bei den ersten Projektschritten haben wir direkt auf dem Main-Branch gearbeitet. Für die späteren größeren Aufgaben, beispielsweise die Website-Entwicklung, haben wir eigene Feature-Branches verwendet.

Codex konnte dort Änderungen vornehmen, ohne unmittelbar den Main-Branch zu verändern.

Danach hat Codex seine Änderungen überprüft und automatisierte Tests durchgeführt. Bei der Website habe ich zusätzlich selbst im Browser getestet.

Nach meiner Freigabe wurden die Änderungen committed, in den Main-Branch übernommen und anschließend auf GitHub hochgeladen.

Hier sieht man einige echte Git-Befehle und die verschiedenen Entwicklungsstände unseres Projekts.

Ein Commit speichert einen bestimmten Entwicklungsstand, sodass Änderungen später nachvollzogen werden können.

Mein wichtigster Lernpunkt ist: Git schafft Transparenz und ermöglicht die Versionskontrolle. Ob der AI-generierte Code tatsächlich richtig ist, muss aber zusätzlich überprüft werden.
