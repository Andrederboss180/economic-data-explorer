# Archiv

Dieser Ordner bewahrt unveränderte Ausgangsmaterialien und später gegebenenfalls ältere, ersetzte Entwürfe auf.

`Pasted text.txt` ist die vom Nutzer bereitgestellte Gesprächsgrundlage. Die aktuelle, bereinigte Projektfassung steht in den übrigen Markdown-Dateien. Bei Widersprüchen gilt die spätere dokumentierte Entscheidung in `docs/decisions.md`.
