# Literaturrecherche

Ziel sind zwei bis drei belastbare Originalquellen, die folgende Punkte abdecken:

1. Grundidee und historische Einordnung der Phillips-Kurve
2. Instabilität oder zeitliche Veränderung des Zusammenhangs
3. Grenzen einer einfachen Regression von Inflation auf Arbeitslosigkeit

## Vorgehen

1. AI für Suchbegriffe und Kandidaten nutzen.
2. Originalpublikation oder offizielle Institution öffnen.
3. Autor, Titel, Jahr, Publikation, DOI oder stabile URL prüfen.
4. Relevante Passage selbst lesen und Seitenzahl oder Abschnitt notieren.
5. AI-Zusammenfassung gegen den Text prüfen.
6. Nur bestätigte Aussagen in Präsentation und README übernehmen.

Die Ergebnisse werden im [source-tracker.md](source-tracker.md) gesammelt. Der zugehörige Prompt und die Prüfung gehören zusätzlich in das AI-Log.
