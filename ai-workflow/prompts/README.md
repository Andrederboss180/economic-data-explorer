# Promptablage

Für jeden präsentationsrelevanten Prompt speichern wir:

- Ziel des Prompts
- vollständigen Prompt oder die relevante Version
- verwendetes Werkzeug oder Modell, soweit bekannt
- erwartetes Ausgabeformat
- erhaltenes Ergebnis in kurzer Zusammenfassung
- menschliche Prüfung
- Entscheidung: übernommen, verändert oder verworfen

Dateinamen folgen der Arbeitsreihenfolge, zum Beispiel:

- `01-ideation.md`
- `02-literature-search.md`
- `03-api-implementation.md`
- `04-statistics-tests.md`
- `05-website-chart.md`

Wir speichern nicht jede Chatnachricht. Ein Prompt gehört hierher, wenn er eine Entscheidung, einen Codebaustein oder einen präsentierbaren Lernpunkt erzeugt hat.
