# Referenzdaten für die Website

Hier landet später eine für die Website geeignete Kopie des geprüften Referenzdatensatzes. Die fachliche Quelle bleibt `data/reference/`; eine Duplizierung darf nur durch ein dokumentiertes Build- oder Kopierskript erfolgen.

Bis zum geprüften API-Abruf enthält dieser Ordner keine Datenwerte.
